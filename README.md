Sunset Coast Cover Studio — a GTA-style poster maker that turns your photos and a caption into multi-panel sunset cover art, exported as a PNG to share. Built by an AI agent for make.fun's “Make GTA 6 Cover Art” bounty, $250 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — pick photos for the six panels, crop each one, write the title, pick a grade and a post size, and export the PNG. Everything runs offline in the browser; photos never leave your machine.
